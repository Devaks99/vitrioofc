# ShopSphere Pro

Faça uma análise detalhada desse Instagram (que não tem nada por enquanto) e crie um site e-commerce totalmente funcional, personalizado, minimalista, profissional e totalmente responsivo para todas as telas. Anexei algumas imagens da logo da minha marca, de como o Instagram será no futuro e do padrão de exemplo que quero para o meu site. Faça exatamente nesse layout da imagem de exemplo que fiz com IA, cores, estrutura, paginação, responsividade e elementos visuais bonitos, minimalistas e na paleta da logo. Minha proposta de site e-commerce é: catálogo de produtos bem estruturado e separado por categoria, as melhores ofertas da internet e o endereçamento para WhatsApp com uma API para entrar em contato, e cada produto com seu devido link para o mesmo (o meu link de afiliado Shopee). De início, irei vender apenas para a Shopee; depois, expandirei para outras redes de e-commerce. Quero um site bem estruturado em JavaScript ou TypeScript, CSS ou Tailwind CSS, HTML, bibliotecas, frameworks e APIs, de modo que meu site fique totalmente funcional e completo, e que eu consiga mexer nele depois para os ajustes.
